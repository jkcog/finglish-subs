# Chrome Web Store listing copy

## Title
Finglish Subs

## Short description (max 132 characters)
Persian YouTube subtitles in Finglish, with tap-a-word meanings and a practice list.

## Detailed description

Finglish Subs shows Persian YouTube subtitles transliterated into Finglish (Persian
spoken words written with Latin letters), so you can follow along even if you can't
read Persian script yet.

HOW IT WORKS
• Finglish subtitles appear on top of the video, above YouTube's own captions.
• Tap any word to see its English meaning — the video pauses while you look.
• Save words to a built-in practice list, then review them with spaced-repetition
  flashcards.
• Works offline. Online dictionary lookup (Wiktionary) is optional and only runs
  when you ask for it.

GOOD FOR
Anyone learning Persian who wants to understand what's being said in a video
before tackling the Persian script itself — language learners, heritage speakers,
and anyone following Persian YouTube content.

LIMITS
• Only works on youtube.com, and only for videos that have Persian captions
  (manual or auto-generated).
• Finglish has no single standard spelling. Spellings here are one reasonable
  choice, not the only correct one. Words spelled by rule (not from the built-in
  list) are shown with a dotted underline.
• Built-in meanings cover roughly 360 common words and 40 verbs. Other words fall
  back to spelling rules or an optional online lookup.

PRIVACY
Everything — your settings and your saved practice list — is stored locally in
Chrome's extension storage on your own device. Nothing is sent to the developer
or to any analytics service. The only outside request is to en.wiktionary.org,
and only when you choose to look up a word online. Full privacy policy:
https://jkcog.github.io/finglish-subs/#privacy

Source code: https://github.com/jkcog/finglish-subs

## Single purpose description (for the CWS "Permissions" justification form)
This extension's single purpose is to display a transliterated (Finglish) version
of Persian YouTube captions over the video, with word-meaning lookups and a
vocabulary practice list.

## Permission justifications

**storage**
Used to save the user's settings (on/off, text size, auto-lookup preference) and
their saved practice-list words locally in the browser, so they persist between
sessions.

**host_permissions: https://en.wiktionary.org/***
Used only when the user explicitly taps "Look up meaning online" (or enables
auto-lookup) on a word card, to fetch that single word's definition from
Wiktionary's public API. No request is made unless the user asks for it.
